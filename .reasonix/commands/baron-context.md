# Baron Context

Run `baron capability check --adapter reasonix`, `baron runtime check --adapter reasonix`, `baron autopilot status`, and then `baron context --reasonix`. Use the shared Baron Vault for durable memory; Reasonix-local state is only an adapter surface. For architecture, dependency, impact, entrypoint, ownership, call-flow, refactor, or cross-module work, run task context first and verify selected source files before treating graph hints as proof.
